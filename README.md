# TrademarkChain - Trademark Registration System

A blockchain platform for registering trademarks, managing brand identities, and documenting prior art for trademark protection.

## Features
- Trademark registration and filing
- Brand owner authorization
- Trademark status tracking (pending/registered)
- Multiple trademark classes support
- Prior art documentation

## Smart Contract Functions
- Register new trademarks with validation
- Approve trademark registrations
- Retrieve trademark information
- Track registration status
- Query total registered trademarks

## Usage
Enables secure trademark registration and management through blockchain verification and immutable record-keeping.
